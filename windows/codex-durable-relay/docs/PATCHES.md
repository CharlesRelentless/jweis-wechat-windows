# 本仓库的中继恢复修正

本目录来自 [codex-durable-relay 固定版本](https://github.com/rdcamelot/codex-durable-relay/tree/e5f82131ba649737cc60893ae19ce90f0e55aa37)，保留原 MIT 许可证和版权声明。它是独立的可选 Windows 组件，不由微信桥接启动，也不是 OpenAI 官方修复。

## 包含的修正

1. 安装失败且 hosts 清理未确认时，保留受保护的恢复注册，禁用用户转发启动路径。仅允许维护任务重试清理，避免删除最后一个清理入口。
2. 卸载和固定路径 hosts 清理不先依赖 settings。配置缺失或损坏时仍可进入恢复；卸载先禁用用户启动任务，只有确认服务已停止才继续。
3. 增加 `scripts/Recover-EarlyInstall.ps1`。仅在不存在自有任务、服务、监听和 hosts 标记时处理固定的部分安装目录，拒绝目录重定向，并提供 `-ReviewOnly`。它不代替正常卸载。
4. 两个固定受保护的 SYSTEM 脚本入口使用进程级 `RemoteSigned`，解决未配置用户策略时默认 Restricted 阻止初始化的问题；不持久改变机器/用户执行策略，组策略优先级保留。
5. 本仓库公开文件检查的精确允许列表补入上述恢复脚本、回归测试和脱敏来源说明；不允许私有验证目录、日志、账号、hosts 备份或构建载荷进入源码。

安装失败、settings 缺失/损坏、极早期复制失败及 SYSTEM 脚本策略均有隔离回归。构建和测试使用临时目录或模拟系统接口，不应安装服务、修改系统 hosts 或操作已有中继。

## 验收边界

2026-10-25 的本机历史记录包含：Dot 原生读取已有 Codex 对话、向本人指定的原对话发送一次接续指令、核对目标回复及 Dot 读回，以及运行中停止清理和重新启动恢复。这是当时、该主机上的功能证据；原始记录和标识保持私有，不能据此宣称当前所有连接已恢复。

完整隔离套件为24项 Node 测试和147项 PowerShell 检查，共171项。当前发布需重新执行 `scripts/Test.ps1` 并以真实退出码为准。Windows CI 在 Node 22/24 上构建和运行隔离检查，不做实际安装。

真实关机/注销、断电、干净虚拟机首次安装和任意版本 Codex 的兼容性不由这些测试证明。本目录不修复 `AbsolutePathBuf deserialized without a base path`，也不修复微信 MCP 插件发现、OAuth、订阅或手机收件；这些必须另行验收。
