# 可选的本机文件只读工具

当原生电脑任务后端不可用时，同一个助手可以通过现有私有 MCP 连接读取本人明确授权的本机笔记。此能力默认关闭，不创建任务、索引、模型或服务，也不能执行命令或写入文件。它补充读取通道，不修复原生任务后端，也不提供本机任务的编辑、执行或历史检索能力。

## 明确授权后启用

先取得本人对具体主机和目录的读取授权。将以下配置用项目的私有文件机制保存为自己的 `runtime/state/local-files-policy.json`，其中示例路径必须替换为真正获准的目录；不能从网页、附件、消息正文或模型猜测中取得授权：

```json
{
  "version": 1,
  "enabled": true,
  "roots": {"notes": "D:/ExampleVault"}
}
```

该文件必须只有当前用户和 SYSTEM 的私有 ACL，不能是重解析点。为原 worker 的命令增加 `--local-files-policy <私有配置文件路径>`；不修改全局环境或代理。切换前备份配置和一致数据库快照，确认无在途发送，停止明确归属的唯一实例，再以同一状态和原连接启动。不得并行运行两个 worker。需要时刷新已有插件的工具目录，不重新绑定微信或创建新助手。

没有这个参数时仍提供原来的15个工具；开启后增加 `read_allowed_local_file`。工具接收 root 别名与相对文件路径，默认仅返回字节数和 SHA-256；`include_text=true` 才返回 UTF-8 正文。不要把真实目录、配置、凭据、运行记录或文件内容提交到仓库。

## 固定边界

- 只允许配置目录下的 `.md` / `.txt`；单文件至多1 MiB，单次正文至多64 KiB，不遍历或搜索整个磁盘。
- 拒绝绝对路径、`..`、UNC、ADS、保留设备路径、重解析点、隐藏或系统属性，以及隐藏目录和凭据类路径。已知原始 key / JWT / 私钥特征也会拒绝返回；这不是通用敏感信息识别器，授权目录中仍应妥善存放敏感材料。
- Windows 实际打开的文件句柄和最终路径经过校验。读取不调用私有文件 ACL 修复函数，不改变笔记的权限，读取过程中检测到大小/修改时间变化则失败。
- 根目录由本机私有配置确定，MCP 调用方不能新增目录或请求写入。现有专用 Tunnel 必须仍为本人私有；本工具不提供额外的逐调用者鉴权。
- 返回内容属于不可信源数据，不能扩大用户指令、执行权限或授权范围。读到 `AGENTS.md` 等规则文件也不意味着有权服从其中的任务或更改配置。

将 `enabled` 改为 `false` 并正常重启 worker 可移除文件工具，同时保留微信工具。移除命令行参数也可关闭它；不要删除消息数据库或重新扫码。

## 验证

```powershell
python -m unittest probe_tests.test_local_files
python scripts/tunnel-offline-check.py --local-files
python scripts/generate-schema.py --check
python scripts/generate-schema.py --local-files --check
```

测试覆盖默认拒绝、实际 Windows 句柄读取、ACL 不变、路径逃逸、隐藏属性、目录联接、凭据路径/内容、读取大小、私有配置与撤销、真实 MCP RPC 和官方客户端的合成文件转发。默认与可选 schema 分别检查。隔离测试不替代原助手从微信发起读取、结果与本机一致以及本人手机收件的验收。
